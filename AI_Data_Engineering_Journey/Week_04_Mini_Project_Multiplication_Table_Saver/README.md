---

## Mini Project 01 — Multiplication Table TXT Saver

### Project Goal

The goal of this mini project is to create a Python program that generates multiplication tables for a selected range and saves the result into a text file.

The program also allows the user to load an existing saved multiplication table file if it already exists.

---

## Required Features

1. User can enter the start table and end table.
2. Program generates multiplication tables for the selected range.
3. Program formats the multiplication table result clearly.
4. Program creates an output folder if it does not exist.
5. Program saves the result as a `.txt` file.
6. Program reads the saved file again to confirm the result.
7. Code is organized into functions.
8. Notebook includes explanation, code, output, and summary.

---

## Topics Covered

- Creating a simple multiplication table generator
- Using `input()` to receive the start table and end table
- Converting user input with `int()`
- Using `for` loops and `range()` to generate multiplication tables
- Using nested loops for repeated table generation
- Formatting multiplication table output with f-strings
- Defining functions to organize program logic
- Creating folders with `os.makedirs()`
- Using `exist_ok=True` to avoid folder creation errors
- Checking whether a saved file exists with `os.path.exists()`
- Saving generated multiplication tables to a `.txt` file
- Reading the saved multiplication table file to confirm the result
- Using a `while` loop to allow the user to run the program again
- Organizing generated text files inside the `assets/Week04/Mini_Project_01` folder

## Function Design

The program is organized into reusable functions.

| Function | Description |
|---|---|
| `create_table()` | Generates multiplication tables for the selected range and saves the result |
| `save_table_file()` | Saves the generated multiplication table list into a text file |
| `read_saved_table()` | Reads and displays the saved multiplication table file |

---

## Program Flow

```text
Start
  |
  v
Create output folder if it does not exist
  |
  v
Check if a saved multiplication table file exists
  |
  +--> If file exists:
  |       Ask user whether to load the saved file
  |       |
  |       +--> If yes: read and display saved file
  |       +--> If no: generate a new table
  |
  +--> If file does not exist:
          Ask user for start table and end table
          Generate multiplication tables
          Save result to text file
          Ask whether to try again
```
