### 1. Unique_Img_Process_with_Python

A Python-based image organization tool designed to simplify personal photo management.

Overview:  
This program helps group similar or duplicate images by adding a numbered prefix to file names. It was created to make duplicate image management easier and more efficient.

Key features:
- Detects similar or duplicate images
- Groups related images into numbered sets
- Renames files consistently for easier organization
- Supports personal photo cleanup and management

Tech Stack:
- Python
- Pillow
- Tkinter
- OS library

### 3. Tip_Calculator

A Python-based tip distribution calculator built with Flet.

Overview:  
This project is a lightweight web application that calculates and distributes tip amounts among multiple people based on hours worked. It supports dynamic row generation, user input handling, and save/load functionality for previously entered names and group size.

Key features:
- Accepts total tip amount and number of people
- Dynamically creates rows for each person
- Allows user input for names and worked hours
- Calculates hourly tip rate automatically
- Distributes tips fairly based on hours worked
- Supports saving and loading previously entered people names and counts
- Can be deployed as a lightweight web app using Docker and Render

Tech Stack:
- Python
- Flet
- JSON
- Docker
- Uvicorn
