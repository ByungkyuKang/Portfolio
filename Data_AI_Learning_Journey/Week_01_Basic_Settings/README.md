## Key Concepts Learned

### 1. Code Cell

A Code Cell is used to write and execute Python code.

Example:

```python
x = 10
y = 20
x + y
```

Output:

```text
30
```

---

### 2. Markdown Cell

A Markdown Cell is used to write explanations, notes, headings, lists, and tables.

Markdown is useful because it helps organize notebooks like a report, not just a code file.

---

### 3. Kernel

The kernel is the engine that runs Python code behind the notebook.

Variables are stored in the current kernel session.  
If the kernel is restarted, previously stored variables are cleared.

---

### 4. Execution Order

Jupyter Notebook cells can be executed in any order.

Because of this, the visible order of cells and the actual execution order may be different.  
This is important because it can affect the result of the notebook.

A good habit is to restart the kernel and run all cells from top to bottom before saving the final version.

## Useful Shortcuts Practiced

| Shortcut | Explanation |
|---|---|
| `Shift + Enter` | Run the current cell and move to the next cell |
| `Ctrl + Enter` | Run the current cell |
| `Alt + Enter` | Run the current cell and add a new cell below |
| `Esc` | Enter Command Mode |
| `Enter` | Enter Edit Mode |
| `A` | Add a cell above |
| `B` | Add a cell below |
| `M` | Change the cell to Markdown |
| `Y` | Change the cell to Code |
| `DD` | Delete a cell |
| `Z` | Undo deleted cells |
